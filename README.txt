/assets - Папка с картинками
/generate - Пакет для генерации структур из готовой базы данных (для GORM)
/go_proto - Пакет со сгенерированным кодом на GO на основе файлов *.proto из пакета /proto
/model - Пакет со сгенерированными структурами для GORM
/proto - Пакет с proto файлами
/query - Пакет с запросами для структур из /model для GORM
/server - Пакет для реализации функций сервера
/styles - CSS-файлы
/templates - HTML-файлы
